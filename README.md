# Historias de Usuario - Aplicación de Catálogo y Compras

E Las historias de usuario diseñadas para la construcción de una aplicación que permite a los usuarios visualizar productos, gestionar un carrito de compras y proceder al pago son las siguientes:

---

## Historia 1: Pantalla de Inicio de Sesión

**Como** usuario  
**Quiero** iniciar sesión  
**Para** poder acceder al catálogo de productos

### Criterios de Aceptación:
- El formulario de inicio de sesión es fácil de leer y comprender.
- El usuario puede identificar rápidamente dónde ingresar correo y contraseña.
- La interfaz guía visualmente al usuario a completar la acción de iniciar sesión.

---

## Historia 2: Vista de Catálogo de Productos

**Como** usuario  
**Quiero** visualizar los productos y filtrarlos por precio o nombre  
**Para** encontrar rápidamente lo que necesito

### Criterios de Aceptación:
- Los filtros por nombre y precio están claramente visibles *(No funcionales)*.
- El catálogo es fácil de explorar visualmente.
- La experiencia de búsqueda no requiere esfuerzo ni confunde al usuario *(No funcional)*.

---

## Historia 3: Añadir Productos al Carrito

**Como** usuario  
**Quiero** identificar los botones para navegar y añadir productos al carrito  
**Para** no perderme y poder organizar mi compra

### Criterios de Aceptación:
- Los botones para añadir al carrito son visibles.
- El usuario puede entender claramente qué ocurre cuando añade un producto, incluso en un prototipo.
- El diseño refuerza visualmente el flujo natural del proceso de compra.

---

## Historia 4: Pantalla de Pago y Carrito

**Como** usuario  
**Quiero** ver el total de mi compra con impuestos incluidos  
**Para** saber con claridad cuánto voy a pagar antes de finalizar la compra

### Criterios de Aceptación:
- El resumen de la compra se muestra claramente.
- El total con IVA es fácil de identificar.
- La interfaz permite revisar todos los productos y el total.

---

## Historia 5: Eliminar Productos del Carrito

**Como** usuario  
**Quiero** poder eliminar productos del carrito antes de pagar  
**Para** corregir mi pedido si cambio de opinión

### Criterios de Aceptación:
- Cada producto en el carrito muestra claramente una opción para eliminarlo.
- Al eliminar un producto, el total se ajusta de forma visual inmediata.
- El usuario entiende que tiene control total sobre su compra antes de proceder al pago.
